# Clypmint

**The AI that edits your whole video.** Send raw footage or a script and get back a finished video with cuts, captions, B-roll and graphics, in a style you pick or copy from any video link. Then change anything by typing.

- [clypmint.com](https://clypmint.com): the AI video editor for talking videos, podcast clips, ads, montages, gaming highlights and faceless videos
- [Clypmint in Claude and ChatGPT](https://clypmint.com/claude): edit videos from any MCP client at `https://clypmint.com/mcp`
- [Clypmint B-Roll](https://github.com/Clypmint/clypmint-broll): real, verified, licensed B-roll of anything a script names, for any agent (MCP server, REST API, CLI)
